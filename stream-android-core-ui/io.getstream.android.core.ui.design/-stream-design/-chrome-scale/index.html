ChromeScale

@Immutable
data class ChromeScale(val s0: Color, val s50: Color, val s100: Color, val s150: Color, val s200: Color, val s300: Color, val s400: Color, val s500: Color, val s600: Color, val s700: Color, val s800: Color, val s900: Color, val s1000: Color)

A 13-stop neutral ramp for the chrome (structural gray) palette: text, backgrounds, borders, surfaces.

s0 and s1000 are the absolute endpoints (white and black in light, black and white in dark). They absorb the light and dark polarity, so downstream tokens reference chrome stops with the same expression in both themes.
