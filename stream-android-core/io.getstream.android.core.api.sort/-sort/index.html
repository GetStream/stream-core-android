Sort

open class Sort<T>(val field: SortField<T>, val direction: SortDirection) : Comparator<T>

A sort configuration that combines a sort field with a direction.

This class represents a complete sort specification that can be applied to collections of the associated model type. It provides both local sorting capabilities and the ability to generate remote API request parameters.
